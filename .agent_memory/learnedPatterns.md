# Learned patterns

- PSX raw data tracks can mix Mode 2 XA Form 1 and Form 2 sectors even when the ISO filesystem exposes 2,048-byte logical blocks.
- In the reference image, system-area sectors 0–11 are Form 1 and sectors 12–15 are zero-payload Form 2 with computed EDC. The compact system payload is therefore 24,576 bytes after trailing-zero trimming.
- Raw reconstruction must preserve XA subheader semantics independently from ISO 9660 logical content.
- Full-image mismatches are regression-test inputs: identify the responsible byte-level rule, add a failing focused test, and only then fix it.
- `ecmlib` reports a completely zero raw tail as `Mode2Gap` before considering XA-gap semantics. Treat both `Mode2Gap` and `Mode2XaGap` as the reproducible zero XA tail when the XA Form bit is clear.
- A raw mode byte of 2 plus the primary XA subheader's `form2` bit classifies Form 2 regardless of ecmlib's EDC-derived subtype. Duplicated-copy agreement and EDC policy are separate validation concerns. Determine computed Form 2 EDC by successful EDC validation, not by testing whether the stored four bytes are nonzero, because a legitimate computed EDC can equal zero.
- Exact reference layout depends on preserving directory-record order separately from physical file extent order. The sample directory lists `DUMMY.BIN` first even though its data is physically last.
- A deterministic editable layout can remain exact across both references by fixing the PVD at LBA 16, writing four breadth-first path-table copies, allocating the root first, and packing files in the captured `files` order while lazily allocating each missing ancestor directory immediately before its first file. Allocate directories with no file descendants breadth-first after the listed files.
- The reference reconstruction reached byte equality after the first classified diff. The tail-classification regression test was added in a failing state before accepting `Mode2Gap` as the zero XA suffix.
- The manifest is intentionally unversioned for now; Serde's unknown-field rejection remains the mechanism for catching unsupported YAML structure.
- Overwrite is a targeted output policy, not data-directory replacement: preflight every declared destination, reject symlinks and type conflicts, reuse matching directories, and leave unlisted host files untouched.
- Raw BIN replacement retains the temporary-file boundary: write and sync the complete image first, reject stale temporary paths even under overwrite, then install the finished image over the destination.
- Keep authoring manifests free of SHA-1 metadata. Exact reconstruction remains a test invariant established by direct byte comparison and an independently known track SHA-1, not by a hash embedded in editable YAML.
- Original track sector count does not belong in the editable manifest because layout plus trailing-gap policy determines authored size; report the parsed count directly during extraction instead.
- Omit canonical track defaults from YAML: absent `mode` means `2xa`, absent `start_msf` means `00:02:00`, and raw sector size remains the code invariant 2352. Represent modes `1` and `2` as numeric YAML scalars and `2xa` as text.
- When every field in a defaultable section is omitted, omit the section itself instead of serializing an empty map. For `track`, a missing section restores Mode 2 XA, `00:02:00`, 150 trailing sectors, and computed Form 2 EDC; `--include-defaults` remains the explicit diagnostic view.
- Support debugging-oriented explicit defaults as a serialization view rather than changing the manifest's compact default behavior. This keeps ordinary extraction concise while allowing `--include-defaults` to emit every field currently governed by omission rules.
- Treat a 150-sector trailing gap as the canonical authoring default: expose it as `track.trailing_gap`, omit it from compact manifests, restore it during deserialization, and emit it under `--include-defaults`; retain any non-150 value explicitly.
- Model XA subheaders internally as four named fields rather than byte arrays. The named submode serializer remains exhaustively tested across all 256 bitmasks for future streaming-file manifests, but standard ISO/system framing is generated programmatically and omitted from current YAML.
- Canonical PSX ISO framing is deterministic: Form 1 system/file data is `DATA` (`0x08`), the PVD is `END_OF_RECORD | DATA` (`0x09`), later ISO metadata and final file sectors are `END_OF_RECORD | DATA | END_OF_FILE` (`0x89`), and zero-payload system Form 2 is `FORM2` (`0x20`), with all other subheader bytes zero.
- Keep fixed or directly observable system-area properties out of editable YAML: the PSX system area is always 16 sectors, and the compact source length is the current `.system` file size. Use that file size when resolving automatic or explicit Form 1 capacity.
- Form 2 EDC policy belongs to the whole track rather than the system area: system padding and future realtime/audio Form 2 sectors must use the same boolean `track.form2_edc` setting. `true` computes/writes EDC and is the omitted default; `false` writes a zero EDC field and must remain explicit.
- Treat empty ISO 9660 PVD text identifiers as omitted manifest defaults, but retain nonempty identifiers as editable metadata. Fixed PVD values that are not yet customizable belong in parser validation and serializer constants: volume-set size 1, volume sequence number 1, logical block size 2048, and file-structure version 1.
- The reference CD-XA PVD Application Use field is a canonical 512-byte block: all zeros except ASCII `CD-XA001` at PVD byte offset 1024 (offset 141 within Application Use). Generate and validate it in code rather than exposing 1,024 hex characters in editable YAML.
- Render ISO 9660 PVD 17-byte timestamps as `YYYY-MM-DDTHH:MM:SS.cc±HH:MM`, preserving the two centisecond digits and converting the signed timezone byte to 15-minute offsets. Map the canonical all-zero timestamp to an omitted `null` default, and validate calendar and offset constraints before authoring raw bytes.
- Represent the ISO filesystem root as the first ordinary directory entry with reserved path `.`. Require it during validation, exclude it from host-path output and child allocation, and use its entry metadata for the PVD root record plus the root directory's dot records.
- ISO directory records use a seven-byte timestamp for both files and directories: year is an unsigned offset from 1900, there are no centiseconds, and the timezone is the same signed 15-minute unit. Render it as `YYYY-MM-DDTHH:MM:SS±HH:MM` and constrain years to 1900–2155. Until a useful repetition pattern is established, keep recording times explicit on every entry instead of adding manifest inheritance defaults.
- Keep fixed directory-record mechanics out of editable entry YAML until variability is supported: validate and generate file version 1, file flags 0, directory flag 2, zero file-unit/interleave sizes, and volume sequence 1. File length is observable from the host file at build time, so it does not need duplicate manifest metadata.
- Separate logical record order from physical file placement without per-entry type/order fields: `entries` order controls directory records, while a required ordered `files` path list declares file membership and extent order. Treat entries absent from `files` as directories and reject unknown, duplicate, or root file paths.
- Canonical CD-XA directory-record System Use data is deterministic and should be generated rather than exposed as opaque hex: zero user/group IDs, attributes `0x0d55` for files or `0x8d55` for directories, `XA` signature, and zero file number/reserved bytes. Represent nondefault values structurally; Spyro's interleaved records use raw attributes `0x2555` and file number 1, serialized compactly as the `interleaved` attribute plus `file_number: 1`.
- Crash exposes why path-table order and directory extent order are distinct. Its root is at LBA 22, `SYSTEM.CNF` is at LBA 23, and subdirectories are interleaved immediately before their first files (`S0` at 24, `S1` at 28,503, `S2` at 71,985, and `S3` at 101,180) even though the path table still lists directories breadth-first.
- Preserve interleaved Form 2 assets compactly as fixed `.XA` records: four unique subheader bytes plus the 2,324-byte payload. The duplicated subheader, sync/MSF, and Form 2 EDC are deterministic track framing and do not belong in the editable sidecar.
- PSX double-speed XA audio slot cadence follows coding info: 37.8 kHz stereo 4-bit audio uses one sector in eight; mono or 18.9 kHz each doubles the interval, while 8-bit halves it. Coding info cannot identify drive speed globally, so the current author explicitly assumes PSX double speed and must reject a channel sequence that does not fit the derived cadence.
- Mixed XA physical order can be reconstructed without a manifest cadence field. Sort the initially present logical channels and assign them permanently to the final N slots of the coding-info-derived cadence. Apply a channel's Form 2 `END_OF_FILE` at the next group boundary by vacating only its assigned slot; never compact or shift the surviving channels. Form 1 sectors fill leading and vacated slots. This handles both a single logical channel 1 in physical slot 7 and eight Spyro channels that end independently.
- A mixed file may use a noncanonical Form 1 framing template such as 3D Lemmings video/realtime `01 01 42 80`; expose it as structured `xa.form1_subheader`. Preserve Form 1 payloads in the primary asset, generate default framing for its trailing all-zero padding sectors, and treat the final physical Form 1 `END_OF_FILE` bit as generated framing rather than a second reusable template.
- XA `mode2_form2` attributes identify mixed Form 1/Form 2 extents even when the separate `interleaved` attribute is clear. Either attribute requires a `.XA` sidecar in an authored manifest.
- XA `cdda` directory records can reference sectors beyond the supplied data-track BIN. Preserve their explicit `extent` and `length`, omit them from the authored `files` payload sequence, compute PVD logical volume size through their furthest end, and keep emitted BIN size tied to the local data track. Allocate their ancestor directories immediately after the root before local file data when reconstructing the observed multitrack mastering layout.
- Some PSX multitrack data BINs end with a zero XA gap sector whose Form 1 ECC was calculated using the recorded nonzero MSF/mode header. Represent this as default-false `track.noncompliant_trailing_ecc`, accept it only on the final raw sector, and regenerate P/Q parity with the recorded four-byte header while leaving earlier trailing sectors standard.
- Unallocated space inside an ISO track is not necessarily ordinary Form 1 padding. Spyro uses zero-payload Form 2 sectors with submode `FORM2` and the track EDC policy for 13 sectors before `WAD.WAD` and 5,921 sectors before `PETEXA0.STR`. Make that structure visible by interleaving `{gap: N}` items directly among `{path: ...}` items in `files`; list position replaces redundant `before` metadata and avoids absolute LBAs.
- Explicit output paths may name directory trees that do not exist yet. Complete destination/type preflight first, then recursively create the manifest or image parent before opening the output; `--manifest-only` still needs the manifest parent.
