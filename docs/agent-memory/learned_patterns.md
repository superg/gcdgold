# Learned patterns

- PSX raw data tracks can mix Mode 2 XA Form 1 and Form 2 sectors even when the ISO filesystem exposes 2,048-byte logical blocks.
- In the reference image, system-area sectors 0–11 are Form 1 and sectors 12–15 are zero-payload Form 2 with computed EDC. The compact system payload is therefore 24,576 bytes after trailing-zero trimming.
- Raw reconstruction must preserve XA subheader semantics independently from ISO 9660 logical content.
- Full-image mismatches are analysis inputs: identify the responsible byte-level rule, reproduce that rule with the smallest in-memory sector or metadata value, add the focused failing unit test, and only then fix it. Unit tests must not retain or generate image files.
- `ecmlib` reports a completely zero raw tail as `Mode2Gap` before considering XA-gap semantics. Treat both `Mode2Gap` and `Mode2XaGap` as the reproducible zero XA tail when the XA Form bit is clear.
- A raw mode byte of 2 plus the primary XA subheader's `form2` bit classifies Form 2 regardless of ecmlib's EDC-derived subtype. Duplicated-copy agreement and EDC policy are separate validation concerns. Determine computed Form 2 EDC by successful EDC validation, not by testing whether the stored four bytes are nonzero, because a legitimate computed EDC can equal zero.
- Exact reference layout depends on preserving directory-record order separately from physical file extent order. The sample directory lists `DUMMY.BIN` first even though its data is physically last.
- A deterministic editable layout can remain exact across both references by fixing the PVD at LBA 16, writing four breadth-first path-table copies, allocating the root first, and packing files in the captured `files` order while lazily allocating each missing ancestor directory immediately before its first file. Allocate directories with no file descendants breadth-first after the listed files.
- The reference reconstruction reached byte equality after the first classified diff. The tail-classification regression test was added in a failing state before accepting `Mode2Gap` as the zero XA suffix.
- The manifest is intentionally unversioned for now; Serde's unknown-field rejection remains the mechanism for catching unsupported YAML structure.
- Overwrite is a targeted output policy, not data-directory replacement: preflight every declared destination, reject symlinks and type conflicts, reuse matching directories, and leave unlisted host files untouched.
- Raw BIN replacement retains the temporary-file boundary: write and sync the complete image first, reject stale temporary paths even under overwrite, then install the finished image over the destination.
- Integrity metadata must remain optional and advisory so editable manifests do not become content-addressed lockfiles. When explicitly requested, colocate SHA-1 expectations with only the host assets that actually author the data track, hash the immutable source BIN separately, compare exact input bytes before transformation, and compare the final raw track after structural overlays and the selected patch policy. Malformed or pathless expectations are manifest errors; content mismatches are ordered nonfatal build warnings.
- Original track sector count does not belong in the editable manifest because layout plus trailing-gap policy determines authored size; report the parsed count directly during extraction instead.
- Omit canonical track defaults from YAML: absent `mode` means `2xa`, absent `start_msf` means `00:02:00`, and raw sector size remains the code invariant 2352. Represent modes `1` and `2` as numeric YAML scalars and `2xa` as text.
- When every field in a defaultable section is omitted, omit the section itself instead of serializing an empty map. For `track`, a missing section restores Mode 2 XA, `00:02:00`, and computed Form 2 EDC; physical trailing space is always explicit in `files`. `--include-defaults` remains the explicit diagnostic view.
- Support debugging-oriented explicit defaults as a serialization view rather than changing the manifest's compact default behavior. This keeps ordinary extraction concise while allowing `--include-defaults` to emit every field currently governed by omission rules.
- Treat trailing space as physical layout, not track policy. Use a final `{gap: N}` for zero-payload Form 2 sectors or `{gap: N, kind: xa}` for a raw XA tail; do not infer 150 sectors or expose `track.trailing_gap`.
- Model XA subheaders internally as four named fields rather than byte arrays. The named submode serializer remains exhaustively tested across all 256 bitmasks for future streaming-file manifests, but standard ISO/system framing is generated programmatically and omitted from current YAML.
- Canonical PSX ISO framing is deterministic: Form 1 system/file data is `DATA` (`0x08`), the PVD is `END_OF_RECORD | DATA` (`0x09`), later ISO metadata and final file sectors are `END_OF_RECORD | DATA | END_OF_FILE` (`0x89`), and zero-payload system Form 2 is `FORM2` (`0x20`), with all other subheader bytes zero.
- Keep fixed or directly observable system-area properties out of editable YAML: the PSX system area is always 16 sectors, and the compact source length is the current `.system` file size. Use that file size when resolving automatic or explicit Form 1 capacity.
- Form 2 EDC policy belongs to the whole track rather than the system area: system padding and future realtime/audio Form 2 sectors must use the same boolean `track.form2_edc` setting. `true` computes/writes EDC and is the omitted default; `false` writes a zero EDC field and must remain explicit.
- Treat empty ISO 9660 PVD text identifiers as omitted manifest defaults, but retain nonempty identifiers as editable metadata. Fixed PVD values that are not yet customizable belong in parser validation and serializer constants: volume-set size 1, volume sequence number 1, logical block size 2048, and file-structure version 1.
- CD-XA PVD Application Use has at least two coherent standard signatures: the canonical block containing `CD-XA001`, and an observed revision variant with a repeated marker followed by `1 1`. Represent these as named variants and continue rejecting arbitrary opaque 512-byte values.
- Render valid ISO 9660 PVD 17-byte timestamps as `YYYY-MM-DDTHH:MM:SS.cc±HH:MM`, preserving the two centisecond digits and converting the signed timezone byte to 15-minute offsets. Map the canonical all-zero timestamp to an omitted `null` default. Preserve invalid fixed-width timestamp bytes as `hex:<34 lowercase digits>` in the same field instead of inventing a valid calendar value.
- Represent the ISO filesystem root as the first ordinary directory entry with reserved path `.`. Require it during validation, exclude it from host-path output and child allocation, and use its entry metadata for the PVD root record plus the root directory's dot records.
- ISO directory records use a seven-byte timestamp for both files and directories: year is an unsigned offset from 1900, there are no centiseconds, and the timezone is the same signed 15-minute unit. Render valid values as `YYYY-MM-DDTHH:MM:SS±HH:MM`; preserve invalid values as `hex:<14 lowercase digits>`. Keep recording times explicit on every entry because the value, including corruption, is entry-local reconstruction data.
- Keep fixed directory-record mechanics out of editable entry YAML until variability is supported: validate and generate file version 1, zero file-unit/interleave sizes, and volume sequence 1. Preserve the supported hidden flag structurally alongside the file/directory kind bits. File length is observable from the host file at build time, so it does not need duplicate manifest metadata.
- Separate logical record order from complete physical placement: `entries` order controls directory records, while ordered `files` items place file extents, non-root directory extents, and gaps. Explicit `{directory: PATH}` items are necessary when mastering order cannot be inferred from ancestry or file order; reject unknown, duplicate, or root placement items.
- Canonical CD-XA directory-record System Use data is deterministic and should be generated rather than exposed as opaque hex: zero user/group IDs, attributes `0x0d55` for files or `0x8d55` for directories, `XA` signature, and zero file number/reserved bytes. Represent nondefault values structurally; Spyro's interleaved records use raw attributes `0x2555` and file number 1, serialized compactly as the `interleaved` attribute plus `file_number: 1`.
- Crash exposes why path-table order and directory extent order are distinct. Its root is at LBA 22, `SYSTEM.CNF` is at LBA 23, and subdirectories are interleaved immediately before their first files (`S0` at 24, `S1` at 28,503, `S2` at 71,985, and `S3` at 101,180) even though the path table still lists directories breadth-first.
- Represent every mixed XA extent with explicit framed streams and exact placement rather than inferred cadence. `.XA1` records contain both four-byte subheader copies plus 2,048 Form 1 payload bytes; `.XA2` records contain both copies plus 2,324 Form 2 payload bytes; `.XAI` stores strictly increasing extent-relative Form 2 positions as little-endian `u32` values. This preserves malformed or nonsemantic framing without consulting channel, coding info, EOF, or payload content.
- XA `mode2_form2` attributes identify mixed Form 1/Form 2 extents even when the separate `interleaved` attribute is clear. Either attribute requires the complete XA1/XA2/XAI asset triplet, and a triplet is invalid without one of those mixed-file attributes.
- XA `cdda` directory records can reference sectors beyond the supplied data-track BIN. Preserve their explicit `extent` and `length`, omit them from the authored `files` payload sequence, compute PVD logical volume size through their furthest end, and keep emitted BIN size tied to the local data track. Allocate their ancestor directories immediately after the root before local file data when reconstructing the observed multitrack mastering layout.
- Some PSX multitrack data BINs end with a zero XA gap sector whose Form 1 ECC was calculated using the recorded nonzero MSF/mode header. Represent this as default-false `track.noncompliant_trailing_ecc`, accept it only on the final raw sector, and regenerate P/Q parity with the recorded four-byte header while leaving earlier trailing sectors standard.
- Unallocated space inside an ISO track is not necessarily ordinary Form 1 padding. Spyro uses zero-payload Form 2 sectors with submode `FORM2` and the track EDC policy for 13 sectors before `WAD.WAD` and 5,921 sectors before `PETEXA0.STR`. Make that structure visible by interleaving `{gap: N}` items directly among `{path: ...}` items in `files`; list position replaces redundant `before` metadata and avoids absolute LBAs.
- Explicit output paths may name directory trees that do not exist yet. Complete destination/type preflight first, then recursively create the manifest or image parent before opening the output; `--manifest-only` still needs the manifest parent.
- Duplicated XA subheader corruption can be file-local and affect both copies rather than taking the simple form of one zeroed copy. Interactive CD Sampler Volume 4 has 5,726 mismatches confined to three streaming extents; byte 0 remains a matching file number `1`, while the remaining bytes are largely garbage-like. The primary submode's Form 2 bit still matches sector protection exactly, whereas the duplicate's bit would misclassify 2,794 sectors. Preserve classification from the primary copy.
- Keep raw-sector replacement separate from the policy that authorizes it. Extraction may emit complete sector patches only for individually analyzed source fingerprints, and any difference outside those registered LBAs must remain fatal.
- Treat the first XA subheader as authoritative even when its fields are nonstandard; the second four-byte copy is redundancy and must not influence form classification. Interactive CD Sampler Volume 4 shows that malformed copies can come from authoring-buffer leakage: in 658 `DEMO00.XA` mismatches, bytes 1–3 of each header slot exactly repeat bytes one 2,048-byte logical block later in the same sector. Other malformed regions show stale media-like data without a reproducible transform. Valid EDC over the original mismatched pair means the anomaly existed before mastering protection, so it must be preserved rather than corrected as a read error.
- A complete 2,352-byte sector replacement is simpler and safer than a byte overlay for corruption recovery: generate the entire canonical image first, then install the raw sector literally and regenerate nothing afterward. The replacement can therefore restore damaged sync, MSF, mode, subheaders, payload, EDC, and ECC together.
- Automatic raw-sector replacement remains unsafe when the semantic difference is unexplained. Preserve primary and duplicate XA subheaders directly in XA1/XA2 records when they are valid authored framing; reserve patches for approved corruption recovery.
- Do not interpret `coding_info` merely because a sector is Form 2; XA audio coding fields are meaningful only when the audio submode is genuinely semantic. Malformed streams can have payload-like primary channel/submode/coding bytes whose random Form 2 and audio bits still determined physical mastering. `MAGMUS.STR` demonstrates this with uniform Form 2 slot residues, reserved coding bits, mutually incompatible derived cadences, and a `0.998575` coding-byte distribution correlation with its payload. Preserve those primary bytes exactly, but do not derive multiplex order from them without a separately approved physical-order representation.
- Separate physical authority from semantic validity for XA subheaders. The primary Form 2 bit can be the byte that actually drove mastering and protection while the primary channel, submode, and coding-info fields are buffer contamination. A repeated value exactly 2,048 bytes later in the same sector is strong evidence of a circular-buffer alias; count nonzero matches separately because long zero regions can create misleading correlations. Raw `CdlReadS/N` streaming can consume sector data without enabling hardware ADPCM, but hardware XA-ADPCM playback and filtering still depend on meaningful subheader fields.
- Test alleged XA cadence independently from the submode bit. A strong 4-bit XA-ADPCM content signature is 18 consecutive 128-byte sound groups whose two sets of four sound-parameter bytes are duplicated and whose filter/range nibbles are valid. If the first 16 groups occur only in 2,048-byte Form 1 chunks, or Form 2's additional 276 bytes are zero or duplicate existing payload, the file is more likely a custom logical data stream containing embedded compressed audio than a hardware-playable XA interleave. Preserve the accidentally mastered physical form separately from any semantic content classification.
- Coherently framed ordinary Form 1 payload files stay framing-free. Generate primary and duplicate XA subheaders during build and use named entry policies for coherent noncanonical endings. If a file-local primary/copy sequence cannot be represented by those policies, promote that file to explicit indexed XA1/XA2/XAI assets rather than adding raw framing to its ordinary payload asset.
- ISO 9660 Volume Space Size is a logical-disc property, not necessarily the supplied data-track BIN length. Infer it from the authored track and external CDDA extent ends, but preserve a larger nondefault `primary_volume.volume_space_size` explicitly without padding the raw BIN. Interactive4 records 294,418 logical sectors while its data-track asset has 272,183 sectors; this was the only post-XA1/XA2 reconstruction mismatch, at PVD byte 80 plus derived protection.
- Interactive4 proves exact irregular reconstruction without cadence or raw overlays: storing all Form 1/Form 2 framed records and their extent-relative positions reproduces 5,726 duplicated-copy mismatches and the full SHA-1 `124146d68022f1ba72b8221be60d1a086725af06`.
- For collection validation, select only the first non-AUDIO `TRACK` declaration from each CUE and require its mode token to end in `/2352` (including `CDI/2352`). Later tracks can be labeled as data while containing sector streams that are not ISO filesystem images, so they must not enter the catalog queue. INDEX, pregap, and audio-track timing remain irrelevant.
- A shrinking failure queue is a better human-controlled iteration artifact than an append-only pass/fail journal. Use a headerless two-column CSV of ROM-relative data path and self-contained reason: discover all candidates only when the final CSV is absent, then use the existing CSV as the exclusive retry set and remove entries as they pass.
- Quote both fields on every failure CSV row for a visually consistent artifact; keep using the standard CSV reader so older minimally quoted files remain valid retry inputs.
- Stream failures to an fsynced `{output}.tmp`, copy the prior final file through an fsynced temporary backup into an atomically replaced `{output}.bak`, and only then atomically install the new final CSV. An interrupted run leaves the authoritative final file intact, while a completed all-pass run deliberately installs an empty CSV.
- Delete image-sized extraction and rebuild artifacts after every catalog attempt. Keep complete normalized command diagnostics inline in the failure CSV rather than creating journals or per-attempt logs; exact pass status still requires streaming byte equality, not merely matching process exit codes.
- Long sequential validation runs should show a compact cumulative pass rate after every completed attempt, using the completed-attempt count as the denominator: `[completed/total, rate: N.NN%] STATUS ...`.
- XA permission bits occupy the lower eleven bits of the directory-record attribute word independently of named high-bit attributes. Preserve nondefault permissions as a numeric structured field and validate that they cannot overlap the attribute mask.
- A single global subheader toggle is insufficient for observed discs. Model coherent policy at the narrowest stable scope: system final Form 1 sector, ISO metadata, or individual entry. Detect only patterns that apply consistently across every sector governed by that policy.
- The system-area Form 1-prefix/Form 2-suffix rule includes both endpoints: all 16 Form 1 sectors and all 16 zero-payload Form 2 sectors are valid homogeneous cases. An EOF bit confined to the last Form 1 system sector is a coherent named variant.
- Catalog failures should be grouped by byte offset and normalized error before changing format support. Repeated coherent structures deserve focused regression tests and semantic manifest fields; corruption should be analyzed rather than categorically skipped. When semantics are impossible but byte width and ownership are fixed, prefer a narrowly bounded hex fallback over relaxing validity or adding a general patch.
- An explicit directory placement may legally follow a file physically stored under that directory. When walking a file's ancestors, do not lazily allocate an ancestor that has its own later `{directory: ...}` item; path-table references can point forward to that explicit extent.
- ISO directory kind comes from the ISO flag, not the XA attribute word. Action Replay discs consistently use permission-only `0x0088` System Use words for both files and directories; preserve an omitted XA directory bit on directories, but continue rejecting a file that claims the XA directory bit.
- PVD Volume Space Size may be smaller than the physical data-track BIN when structured terminal gap sectors follow all referenced content. Validate an explicit value against the furthest directory/file/external extent, not against physical track length; default inference can still use the physical length.
- Ordinary Form 1 file endings have a third coherent policy besides canonical `0x89` and plain DATA `0x08`: DATA+EOF `0x88`. Store it as `end_of_file_data`, detect it from both matching subheader copies, and generate only the final file sector with that submode.
- The PVD root directory record can repeatedly use parent identifier byte `1` instead of canonical current identifier `0`. Preserve that bounded quirk as `primary_volume.root_directory_identifier`, not as an opaque PVD patch.
- Mixed XA framing can be physically authoritative even when directory attributes omit both `interleaved` and `mode2_form2`. Infer sidecars from observed Form 2/XA-gap sectors, allow an explicit XA1/XA2/XAI triplet with empty attributes, and keep the directory-record attribute word unchanged.
- Canonical zero XA gaps can occur inside a mixed extent. Store their strictly increasing positions in optional `.XAG` sidecars, require them to be disjoint from `.XAI`, and reconstruct them as structured XA gaps; this covers repeated streams and isolated gap slots without storing raw sectors.
- XA `file_number` in an entry's System Use metadata also governs generated ordinary file and directory sector subheaders. Applying it to every sector in that entry's extent reproduces root directories with `[1,0,0x89,0]` while sidecar extents retain their own exact framing.
- A zero-payload protected Form 1 separator with matching copies, channel/coding zero, and only EOF submode is a structured physical gap rather than opaque padding. Represent it in `files` as `kind: form1` with an explicit XA subheader and accept it only outside ISO file/directory extents.
- Path-table copies can use a coherent per-copy DATA-until-final subheader policy independently of other ISO metadata. Detect the policy across every declared path-table extent and apply it separately to each copy during layout.
- Do not generalize known corrupt directory-record scans. Aitakute and All Star Racing 2 have garbage before/after valid records, while MLB 2005 is another malformed-record case. Analyze their byte layouts individually and require a bounded recovery rule that distinguishes valid both-endian extent/length fields from garbage before accepting them.
- ISO 9660's associated-file flag (`0x04`) is a real structural bit independent of the directory bit. Preserve it as entry `associated` on both files (`0x04`) and directories (`0x06`) instead of rejecting it as an unknown flag.
- `CD Rep 2.0.131` is a coherent PVD Application Use signature used by a family of cheat discs. Its directory writer puts the mandatory pad byte after, rather than before, the 14-byte XA System Use field whenever the identifier length is even. Detect that exact XA-shaped shift and regenerate the trailing-pad convention only for the named CD Rep policy.
- ISO path-table optional-copy pointers can legitimately be zero. Require the first little-endian and first big-endian tables, treat `[L, 0, M, 0]` as explicit `path_table_copies: single`, and never validate or write an absent pointer as LBA zero.
- A zero-payload protected Form 1 gap remains structured when its matching subheader copies carry DATA/EOR/EOF combinations other than bare EOF. The explicit manifest subheader is sufficient authority as long as the Form 2 bit is clear. Split a larger all-zero interval into maximal uniform Form 1 and Form 2 runs, then retain those different gap kinds in order during layout.
- PVD framing and file framing can vary independently. `metadata_subheader: iso_metadata` captures a PVD using `0x89`, while an entry-level `sector_subheader: iso_metadata` captures only multi-sector files whose every sector uses `0x89`; do not infer a global all-file policy from the PVD alone.
- Some mastered ISO directory identifiers are deterministic printable ASCII but outside Level 1, including `~`, `-`, `!`, trailing dots, and dotted directory names. Keep Level 1 as the safe default and emit explicit `identifier_policy: nonstandard_ascii` only after extraction observes such a component; continue rejecting traversal, path separators, backslashes, and non-ASCII bytes.
- A large overlapping-extent cluster is not one unconditional alias rule. Exact, nested, and partial ranges can share one bounded representation only when the overlap is file-only, every physical sector is Form 2, and every entry declares XA interleaving/Form 2; bogus nonzero lengths at extent zero remain a separate corruption subtype.
- Gap redundancy depends on the complete physical gap description, not only Form 1 versus Form 2. Adjacent Form 1 runs with different XA subheaders are separate authored regions and must remain ordered; reject only adjacent gaps whose kind and explicit subheader are identical.
- DATA+EOF (`0x88`) is a coherent final-sector policy beyond ordinary files. Some discs apply it to the PVD, terminator, single-sector directories, and every one-block path-table copy. Model the global metadata policy and the per-directory/path-table final policy explicitly; for multi-block regions, generate DATA on preceding blocks and DATA+EOF on the final block.
- Multiple primary volume descriptors can be deliberate redundancy. The observed cheat-disc family writes three byte-identical PVD blocks with PVD framing before the terminator and shifts path tables/directories by two sectors. Preserve a bounded copy count and require every extra PVD to be byte-identical instead of accepting arbitrary descriptor sequences; supplementary/Joliet descriptors remain a different unsupported structure.
- ISO directory packers can deliberately decline an exact fit: if the next record length equals the bytes remaining in a sector, a mastering family leaves those bytes zero and starts the record in the next sector. Detect that exact boundary signature across directory extents and preserve it as a named packing policy; do not confuse ordinary short padding or random directory garbage with the rule.
- XA CDDA directory records are external references, not physical placements in the authored data BIN. Their structured attribute is sufficient to preserve a zero-length placeholder, extent zero, or an address range overlapping local data without allocating payload sectors. Continue excluding them from `files`, while retaining their exact extent and length in directory records and logical-volume inference.
- A PVD-size failure is not automatically evidence that the PVD should be relaxed. The current 15-disc cluster has one final directory record whose declared length exceeds the logical volume, and several exceed the physical BIN under 2,048-byte extent accounting; many also expose overlapping or bogus extents. Treat these as ambiguous or corrupt metadata until a physical-sector-count rule can reproduce both directory length and extent boundaries.
- An XA-subheader error reported as “ISO metadata” can actually identify a large nonzero physical extent that no directory record references. Detect referenced file/directory placements first; preserve each unsupported intervening range as an explicit indexed `xa_extent`, and exclude only that exact LBA range from ordinary ISO metadata framing validation. XA1/XA2/XAI/XAG retain logical payloads and both subheader copies while EDC/ECC remain regenerated.
- Do not force unrepresentable Form 1 file framing through a global or entry-wide subheader policy. Promote only that file to indexed XA assets when its sector sequence cannot be expressed as canonical, all DATA, DATA+EOF-final, or all ISO-metadata. Preserve a non-sector-aligned directory-record length separately as `xa.logical_length`; the indexed sector count must equal its 2,048-byte ceiling.
- A custom directory subheader can still have a coherent bounded rule. Treat `xa.framing_subheader` as the exact replacement for DATA-framed directory sectors, while `data_until_final` or `end_of_file_data` continues to control the final sector. This covers a custom DATA+VIDEO prefix followed by canonical ISO metadata without retaining directory payload bytes.
- System-area anomalies can occur at any Form 1 position and in only one duplicated-copy byte. Keep the compact `.system` payload and Form 1 count, but emit sparse indexed `form1_framing` overrides for sectors whose primary/copy pair differs from the generated DATA or final DATA+EOF policy. Regenerate protection around the explicit pair.
- Removing an XA validation gate can expose an unrelated structural mismatch. Blackjack's later `M01.XA` overlap was eventually proven to be a coherent Form 2 reference stream, while Digimon World 2 advances from an unreferenced multi-channel XA region to a PVD path-table-size inconsistency. Keep genuinely independent reasons queued and do not broaden one representation into a corruption workaround.
- Failure queues generated before first-data-track-only CUE discovery may already contain secondary data tracks. For the Redump-style filenames in this collection, retain names with no `(Track N)` suffix plus `(Track 1)` and `(Track 01)`; remove every other numbered track suffix, preserving a backup of the unfiltered CSV.
- The 85-image physical-overlap cluster splits cleanly: 47 images contain nonempty directory records at LBA zero and remain corruption cases, while 38 images contain 306 connected components of file-only overlaps. Every sector in those 306 components is raw Mode 2 Form 2, and every overlapping entry declares `interleaved` or `mode2_form2`; do not apply this rule to directory overlaps, pre-root extents, Form 1 sectors, or entries without those attributes.
- Overlapping logical Form 2 XA files are directory references, not separately authored payload placements. Preserve each entry's exact `extent` and `length`, remove those paths from physical `files` placement, and author each connected sector union once as an indexed `xa_extent`. Build must reject any local fixed XA reference not wholly covered by one such physical extent. This representation rebuilt all 38 coherent collection cases byte-for-byte.
- Invalid ISO times are not safely repairable by normalizing the calendar. The current 32-image cluster contains 562 invalid entry timestamps but only eight seven-byte values (zero month/day, 1900-02-29, and 1995-06-31 variants), plus two identical invalid 17-byte PVD creation times. Their duplicate directory copies agree, so one `hex:` fallback per existing time field is sufficient and rebuilt all 32 images exactly.
- Path-table copy count and physical endian order are independent. Seven Action Replay/GameShark discs place their sole big-endian table at LBA 20 and little-endian table at LBA 21, requiring `path_table_order: big_endian_first`; all seven also carry reserved PVD bytes `37 29`, preserved through bounded `primary_volume.reserved_hex` rather than Application Use or a whole-sector overlay.
- ISO 9660 owns a fixed 512-byte PVD Application Use region, so noncanonical values can be preserved as bounded metadata without retaining a raw sector. The current 32-image cluster contains 26 exact values: most keep `CD-XA001` plus an eight-byte mastering residue, while others have a space-filled prefix, `EB111`, or an entirely zero region. Keep known signatures named and compact; use exact-length `application_use_hex` only for unmatched values. Twenty-seven images then round-trip exactly and five expose independent later failures.
- An invalid PVD root directory-record length can alias following fixed PVD fields without adding new bytes. Two Russian unlicensed discs store length 68, so the nominal 34-byte record claims the first 34 space bytes of the Volume Set Identifier. Preserve only the overlong length and regenerate the aliased bytes from the ordinary PVD fields; do not duplicate them as opaque System Use data.
- Directory slack is distinct from malformed directory-record scanning. Fifty-two current byte mismatches have valid records followed by a zero record terminator and later nonzero bytes inside the same declared 2,048-byte directory extent. Preserve the trimmed trailing region as entry-local `{offset, hex}`, and reject it if edited records overlap the offset or the bytes exceed the allocated directory extent. Root and nested-directory probes across the 512/1024/1536 boundaries rebuild exactly.
- A corrupt nonempty file reference does not need a host asset when its extent is zero, only partly present, wholly beyond the track, or overlaps another physical placement. Preserve the exact directory-record extent and length with `unbacked: true`, remove the path from physical file ownership, and retain any locally present sectors once through the structured gap/XA-extent layout. Keep empty files and external CDDA references under their existing semantics.
- ISO path tables are fixed-size logical metadata even when their directory list is stale or corrupted. Compare each declared little-/big-endian payload with the regenerated hierarchy; if it differs, preserve paired exact-length hex payloads, require optional copies of the same endian to agree, and continue allocating only the declared path-table blocks. This is bounded metadata preservation, not an opaque sector escape hatch.
- PVD Volume Space Size can itself be corrupt yet exactly representable. A nonzero recorded value may be smaller than referenced directory records and smaller than physical content; preserve it independently from authored allocation instead of rejecting the whole image. Fifteen queued unlicensed images combine this with partly missing or overlapping file references and all rebuild exactly once those separate facts are represented.
- Physical overlap fallback should detach only file ownership; directories remain generated structural metadata. Preserve the existing stronger Form 2 XA-reference representation when its conditions hold, then mark any remaining file involved in file/file or file/directory overlap as an unbacked fixed reference and preserve the underlying physical sector union once.
- Nonzero bytes after an ordinary file's logical length but before the end of its final allocated 2,048-byte block are filesystem-owned allocation padding, not part of the extracted host file. Preserve the bounded prefix through its last nonzero byte and reject that field on aligned, directory, fixed-reference, or indexed-XA entries. This single rule explains the current 29 first-byte compare mismatches.
- System-area Form 1 sectors need not form a prefix. Run-length physical kinds can represent XA-gap/Form-1/XA-gap layouts while the compact `.system` asset concatenates only Form 1 payloads in physical order. Keep sparse framing indexes absolute to the 16-sector system area, and require all run counts and the total Form 1 count to agree.
- Detect PVD 16-bit storage policy independently from the fixed values stored there. A field-value validation test may intentionally change a canonical value; encoding detection should first distinguish matching both-endian halves from consistently zero big-endian halves, then report the ordinary semantic invariant error.
- A missing XA System Use extension can be a coherent whole-filesystem policy rather than per-record damage. Infer the global policy from the root dot record, require every parsed record to follow it, and keep sector-level XA framing metadata independent from whether directory records carry the 14-byte extension.
- Advancing one failure often exposes a separate corruption. In the current system-area family, structured gaps reveal a supplementary descriptor, all-zero global ISO framing, or a wrong parent-directory extent. Stop at that boundary and model each repeated property separately; do not use a whole-image patch or broaden the preceding fix.
- XA System Use presence can vary at a file-record boundary even when the filesystem-wide rule is otherwise coherent. Preserve ordinary-file omissions as an explicit path list, require the listed paths to be files, and keep directory/dot-record omissions unsupported until a separate pattern is demonstrated.
- The PVD root directory record and the root directory's dot record can carry different seven-byte recording times. Preserve a PVD-local override only when they differ; do not change the filesystem entry timestamp or retain the whole PVD root record.
- Some mastering tools timestamp every non-root `..` record with the current directory rather than its parent. Infer this only as a consistent disc-wide policy from distinguishable records, reject times matching neither directory, and patch only the generated parent record's timestamp bytes.
- Physical spacing between ISO path-table copies is independent of logical table size. A uniform per-copy stride can be represented as canonical XA-gap padding after each present table, shifting subsequent pointers and the root extent without preserving opaque sectors.
- A supplementary/Joliet volume descriptor is not a standalone metadata-sector exception when it points to its own path tables and root hierarchy. Support it only as a complete secondary filesystem representation; preserving the descriptor block alone would create an internally inconsistent rebuild.
- A malformed directory can retain an exactly identifiable suffix rather than arbitrary garbage. All five Aitakute images omit the first eight bytes of the `CDROM` dot record, so its remaining 40 bytes start at offset zero and the valid parent record starts at offset 40. This repeated family-wide rule is recoverable without permissive record scanning, but remains explicitly marked as corruption until a structured omission policy is implemented.
- A nonzero Form 2 system-area sector can combine three independent pre-derived-protection anomalies: bounded nonzero payload residue, distinct primary/copy subheaders, and an invalid zero EDC. All-Star Mahjong confines that combination to sector 12 while the other Form 2 system sectors remain canonical; preserve the diagnosis explicitly rather than treating every nonzero system payload as the same corruption.
- Exact-fit directory records can expose authored buffer residue in the next logical block. Both All Star Racing 2 releases fill offsets 0–1023 with 18 valid records and then store 1024 bytes of non-record data; all four path tables independently confirm that no subdirectory is missing. The USA residue exactly duplicates half a later `GAME.PLB;1` sector, while Europe's is unique. Treat the tail as bounded directory slack rather than resynchronizing on accidental record-like bytes.
- A Type-2 Joliet descriptor must be modeled with its complete secondary path tables and directory tree. Map each Joliet file to one unique primary file by identical extent and length, keep the UCS-2BE display path independently editable, and reject ambiguous or missing mappings. Descriptor-only preservation is internally inconsistent.
- Joliet metadata ordering is not implied by the descriptor pointers. The observed families interleave primary and Joliet endian tables in different orders and may insert zero XA-gap sectors between them; preserve the six logical metadata objects plus explicit gaps in one ordered `metadata_layout` sequence.
- Joliet fixed descriptor strings have three independent bounded padding quirks: zero versus UCS-2 space padding after nonempty values, zero versus space filling for empty values, and a mixed raw Volume Set Identifier field. The odd final bytes of the three 37-byte file-identifier fields are separate again. Preserve these locally instead of retaining the whole SVD.
- Joliet file identifiers do not universally include `;1`. A per-file `omit_version` flag preserves that coherent mastering choice while the `source` field still provides primary-file ownership and extent identity.
- A metadata directory already assigned by explicit primary/Joliet metadata layout must not be relocated by the fixed-reference ancestor preallocation pass. Check the placed bit before allocating an external reference's ancestor, or path-table extents and physical image length both drift.
- Raw XA framing follows descriptor type, not a range that includes the terminator. Type 1 PVD and Type 2 SVD blocks use PVD framing; the Type 255 terminator uses the ordinary metadata policy even when it immediately follows an SVD.
- Primary and Joliet directory trees can alternate sector-by-sector and later reappear among file extents. Whole-tree metadata groups are valid only when each tree is physically contiguous; otherwise emit every directory as a volume-qualified item in the ordinary ordered physical layout and require complete, duplicate-free placement of both trees.
- A zero-payload Form 2 gap can coherently use zero EDC even when the rest of the track computes Form 2 EDC. Preserve a uniform gap-local `form2_edc` override instead of weakening the track policy or treating the sectors as opaque XA data.
- A 2,352-byte all-zero sector has no sync, MSF, mode, subheader, payload framing, EDC, or ECC to reconstruct. It is still bounded and deterministic when every sector from that point to EOF is zero: represent the run only as a terminal `raw_zero` gap and reject the same bytes in any interior position.
- Raw `MODE1/2352` is structurally different from Mode 2 XA Form 1 despite sharing a 2,048-byte logical payload. Read Mode 1 at raw offset 16, regenerate it with Mode 1 EDC/ECC, require the entire nonzero track to keep mode byte 1, and reject ecmlib's raw/noncanonical classification rather than treating Mode 1 as an XA Form 1 variant.
- A canonical zero-payload Mode 1 sector is physically protected and should use `{gap: N, kind: mode1}`. Do not infer a terminal gap solely from trailing zero logical payloads because a real file can end with zero blocks; let ordered ISO placements identify unreferenced Mode 1 runs, preserving an independently declared Volume Space Size when the physical BIN extends beyond it.
- Mode 1 has no XA subheader copies. Ignore no manifest framing field silently: require canonical metadata/file policies and reject Form 2 gaps, XA sidecars, unreferenced XA extents, and sparse XA system framing while continuing to preserve CD-XA System Use bytes inside ISO directory records. Full final raw-sector patches remain mode-independent.
- ISO descriptor File Structure Version is a structured one-byte field, not a reason to retain a descriptor sector opaquely. The GameGenius Mode 1 image consistently records zero in both PVD copies and its Joliet SVD; preserve that known nonstandard value as descriptor-local `file_structure_version: 0`, omit the standard value 1, and continue rejecting other values until analyzed.
- A directory-flagged record with length zero is a structural reference, not an empty directory allocation: it cannot contain dot records or own sectors. Preserve it with an entry-local fixed extent/length only when both endian path tables agree and assign it no children; keep it in the hierarchy and path tables while excluding it from physical placement and subheader inference. Do not globally relax dot-record validation for ordinary directories.
- Allocation padding belongs to an authored file's final logical block. Whenever extraction detaches a file into a fixed reference, clear any previously observed padding field because that reference does not author a file allocation and the underlying physical sectors are preserved elsewhere.
- A nonzero directory-flagged reference may point into coherent physical content that is not a directory at all. If every path table agrees on the node and gives it no children, preserve the fixed directory extent/length separately from the physical sector ownership; do not scan high-entropy bytes for accidental records or call the whole sector directory slack. OverBlood 2's `DUMMY` node is the first observed case: one invalid 2,048-byte referenced sector at the start of a larger unreferenced Form 1 region.
- Failure reasons in a shrinking queue can become stale after a broad format feature lands. Re-run exact-path probes before analyzing old `unsupported sector mode` rows; both PlayStation Programmer Tool Runtime Library dumps became clean byte-for-byte Mode 1 roundtrips without another code change.
- Directory-record hierarchy and recorded path-table hierarchy can disagree independently. PoPoRoGue has a childless extent-0/length-0 directory record while every path table retains an additional extent-0 child beneath it. Both nodes own no sectors, so corruption-tolerant extraction can ignore the impossible branch without losing meaningful data and defer restoration of the stale path-table bytes to the final patch.
- Some XA mastering pipelines store a stream's directory-record length as physical sector count times 2,336 rather than ISO logical blocks times 2,048. When consecutive extents prove that convention repeatedly, separate the exact recorded length from physical sidecar sector count; otherwise ordinary overlap fallback wrongly detaches both the oversized record and a healthy following mixed-XA stream. Do not classify the following stream as corrupt merely because standards-based allocation makes the ranges overlap.
- A structured 2,336-byte length convention should affect only directory-record serialization, never physical layout. Infer physical sector count as `recorded_length / 2336`, allocate and index that many 2,048-byte logical payload sectors, and regenerate the nonstandard recorded length from the indexed count. Require exact divisibility plus proof that this physical range does not cross the next placement while ordinary ISO ceiling arithmetic does; this also permits a real structured gap between the stream and the next entry. Matching Joliet records must reuse the primary entry's length encoding so their source extent/length identity remains exact.
- The 2,336-byte stream-length convention is family-wide across both Poxozhdenie Rayany discs, not a Disc 1 exception. Disc 2 independently inferred 115 encoded indexed entries and rebuilt all 288,179 sectors exactly, so the boundary-based inference is preferable to a title-specific manifest override.
- Ren'ai Kouza/Lost Sword and Riichi Mahjong/All-Star Mahjong form two exact malformed system-sector pairs, each with twelve Form 1 data sectors followed by one data-bearing Form 2 sector and three empty Form 2 sectors. A “final data sector is Form 2” policy is insufficient because both pairs also require distinct noncanonical primary/copy subheaders. The user explicitly rejected expanding the YAML with sparse Form 2 framing for this narrow corruption class; defer all four to final patching.
- Do not infer a nonstandard mastering rule from the first invalid-sync error when the image contains many dispersed protection failures. Strider 2 Europe Beta has 54 damaged sync fields, 33 invalid nonzero Form 2 EDCs including three sectors with canonical sync, and at least one Form 1 sector whose protection remains unclassifiable after every sync field is normalized. This is unrecoverable payload/protection damage without an external reference, not a structured raw-header policy; defer it wholesale to final corruption patching.
- A malformed identifier-length error can be directory buffer residue rather than a damaged record. Strike Force Hydra's valid `ART/TEXT` records end at offset 1,536, its path-table node has no children, and the remaining 512 bytes exactly duplicate a region of `DUMMY.RAW`. Normalizing only that protected tail makes the entire image roundtrip. Existing `directory_slack` can author the bytes, but extraction must not generally stop at arbitrary invalid records without independent evidence that no meaningful record is being discarded; keep this decision aligned with the previously classified All Star Racing/MLB residue cases.
- A corrupt final sector can follow an otherwise fully canonical trailing gap. Thrill Kill Beta has 149 valid XA-gap sectors followed by one sector whose sync survives but whose MSF, mode, data, and protection differ from the implied 150th gap in 2,323 bytes. Replacing only that final sector proves the rest of the image roundtrips. Keep the clean gap structurally authored and defer the recorded last-sector bytes to final patching, matching the Fighter Maker decision.
- Missing-leading-byte directory corruption is not unique to Aitakute. All three Tokimeki Memorial PlayStation the Best revisions omit the same first eight bytes of the `CDROM` dot record while retaining its 40-byte suffix and a correctly aligned parent record. Derive the missing prefix from the record length and both-endian extent, then validate the shifted record sequence and zero tail before concluding that extraction loses no meaningful data; do not turn this into permissive resynchronization.
- Retry stale directory failures after adding bounded fixed-reference support. Both Tomb Raider II Europe variants contain three extent-0/length-0, childless directory nodes under `ENG`; both endian path tables agree exactly, so existing `directory_reference` support handles them and both images now rebuild byte-for-byte without title-specific behavior.
- A sector-type failure may be the leading edge of a cross-sector corruption burst. Tony Hawk's Pro Skater Beta first fails on a Form 1 sector whose payload and EDC are intact because only its ECC tail is overwritten; the overwrite then consumes two complete sectors, removing both raw framing and their expected Form 1/Form 2 stream payloads, before framing resumes. Measure protection agreement, raw sync continuity, stream cadence, and duplicate-byte evidence before considering a new sector representation. Missing logical content with no independent source belongs to final corruption patching, not structured YAML; annotate the failure queue with the measured span and lost stream roles rather than retaining only the first detector symptom.
- Exact-fit valid directory records followed by an invalid next-block length can be unique buffer residue rather than a copied file fragment. For Truck Racing, use all four path tables, paired filename/allocation continuity, and a bytewise scan for plausible both-endian records to establish that the second 1,024-byte block contains no lost filesystem entry. Even when existing directory-slack YAML could physically retain those bytes, do not teach extraction to stop at arbitrary malformed records without an explicit corruption policy; preserve the evidence in the failure-queue annotation for later patch work.
- Inline corruption patches should name signed absolute CD LBAs, not track-relative indexes or MSF strings. Resolve `track_start_lba = frame(start_msf) - 150`, then `sector_index = patch_lba - track_start_lba`; this retains intuitive disc addressing for nonstandard and negative track starts while keeping the raw header bytes fully authoritative inside the replacement.
- Keep three representations distinct during recovery: immutable source bytes, a narrowly repaired semantic image, and the canonical image generated from extracted YAML/assets. A source fingerprint authorizes a handler, but exactness comes from proving that canonical and source differ only at registered sectors, then applying those full sectors and comparing every byte and SHA-1.
- A patch must be the final authoring operation. Decode ASCII-whitespace-tolerant hex to exactly 2,352 bytes, require strictly increasing in-range LBAs, copy the sector literally, and perform no header, EDC, or ECC regeneration afterward. This makes even an invalid stored MSF or destroyed mode byte reproducible.
- Missing eight leading directory bytes can also overwrite the raw XA subheader window, so shifting the logical payload alone is insufficient. After deriving the unique dot-record prefix and proving the displaced final eight bytes are zero, regenerate the semantic sector with the independently expected directory file number and ISO-metadata subheader; retain the complete original raw sector as the patch.
- Directory buffer recovery needs both a content boundary and an allocation boundary. MLB's valid records occupy one block while its directory record declares two; a zero-valued `directory_slack` byte at the final allocated offset is a compact deterministic way to preserve the second zero block without inventing data, provided layout sizing includes the slack end.
- A single hierarchy diagnosis may imply many patched sectors. Blood Lines has forty nested directory parent records with the same root-reference contamination; repairing only the first parser failure is incomplete. Group the contiguous LBA range into one warning and retain all forty original sectors.
- Form 2 EDC validity and the authored EDC convention are separate observations. Biohazard combines sparse invalid nonzero EDC values with zero-EDC system sectors and computed-EDC streams; choose one deterministic semantic convention, retain every proven payload window, and register every source sector required to restore the local conventions exactly.
- Completely destroyed stream sectors can be semantically recoverable only when ownership, physical slot, and form are independently proven. Preserve the file's sector count and use deterministic zero Form 1/Form 2 payloads for the missing slots, then let the full raw-sector patch restore the recorded corruption. If cadence or ownership is ambiguous, remain fatal.
- Recovery warnings are part of the extraction contract, not incidental log text. Store category, grouped absolute-LBA/MSF ranges, optional path, and description in `ExtractReport`; print them to stderr, count them in the success summary, and keep exit status 0 only after the canonical/source proof passes.
- When a catalog artifact is named from a CUE rather than its selected BIN, retain the CUE/BIN association during initial discovery and reconstruct it deterministically for retry-only queues. Preflight flat output-name collisions before extraction, and install a successful temporary artifact through a same-directory fsynced staging file plus `os.replace` so later validation failures do not lose the diagnostic output or expose a partial replacement.
- Unbacked status describes physical ownership, not directory-record identity. When detaching a file, retain its XA group/user/permissions/attributes/file number so the ISO record remains exact, but clear indexed assets, gap indexes, logical-length overrides, physical length encodings, custom framing, and allocation padding because the entry no longer authors sectors.
- A directory's advertisement in its parent can carry different XA fields from the directory-local `.` and `..` records. Preserve the latter as one directory-local override and apply it to both self/parent records; do not overwrite the advertised entry metadata or infer physical sector framing from the mismatch.
- Treat the volume terminator's Mode 2 XA framing independently from Type 1/Type 2 descriptors and other metadata. A PVD-framed terminator is a bounded policy, not evidence that path tables and directories share PVD framing. Likewise, an overlong Joliet descriptor root record can be preserved with the existing descriptor-local record-length policy when its extra bytes are exactly the following descriptor field bytes.
- Redump's exact damaged-sector convention is structural, not a filesystem gap or a corruption patch: canonical sync, monotonic MSF, and the track mode remain authoritative while raw bytes 16–2,351 are all `0x55`. Store coalesced absolute-LBA runs at track scope, substitute protected zero semantic blocks without changing physical ownership or extent lengths, ignore those positions as framing/subheader/EDC evidence, then reapply the `0x55` body after canonical sector generation and before optional raw patches. Near-matches must remain ordinary parse failures, and destruction of indispensable metadata must fail explicitly when the zero semantic view cannot be parsed.
- Do not write tests for files or behavior under `scripts/`. Keep product coverage in the Rust library and CLI test suites outside that directory.
